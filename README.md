# Automobile Customization using VR 🚗🕶️

A Virtual Reality platform for real-time automobile customization, built with Unity 3D, OpenXR, and the Oculus Quest 2. Users can explore a 360° virtual showroom and customize a car's color, wheels, and interiors interactively — using hand tracking and VR controllers.

## 🎯 Objective
To replace static, 2D car configurators with an immersive VR showroom where customers can preview customizations in real time, reducing dependency on physical showrooms.

## 🛠 Tech Stack
- **Engine:** Unity 3D
- **VR Framework:** OpenXR, XR Toolkit
- **Hardware:** Oculus Quest 2
- **3D Modeling:** Blender
- **Scripting:** C#

## ✨ Features
- 360° interactive virtual showroom with VR locomotion
- Real-time color, wheel, and interior customization
- Hand tracking and gesture-based controls
- Optimized rendering (60+ FPS) via LOD and texture compression

## 📐 Design
- **Architecture:** 4-layer system — UI Layer, Application Layer, Data Layer, Hardware Layer
- **Use Case:** Supports both User (customize/navigate) and Admin (manage models/optimize performance) roles
